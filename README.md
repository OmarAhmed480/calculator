# 🧮 Calculator

A simple and modern **Calculator App** built with **Flutter**.
The app provides a clean interface for performing basic arithmetic operations quickly and easily.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Decimal calculations
* 🧹 Clear and reset calculations
* 📱 Responsive and user-friendly UI
* ♻️ Reusable Flutter widgets

## 🛠️ Technologies Used

* **Flutter**
* **Dart**
* **Material Design**

## 📱 App Overview

The Calculator app is designed to provide a simple and intuitive experience for performing everyday mathematical calculations.

### Main Operations

| Operation | Description       |
| --------- | ----------------- |
| `+`       | Addition          |
| `−`       | Subtraction       |
| `×`       | Multiplication    |
| `÷`       | Division          |
| `C`       | Clear calculation |
| `=`       | Display result    |
